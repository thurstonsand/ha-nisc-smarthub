# AGENTS.md

`ha-nisc-smarthub` is a HACS-installable Home Assistant custom integration for NISC SmartHub electric co-op portals. It scrapes hourly usage with the portal's time-of-use classification, prices it under the member's rate schedule, and writes usage and cost as long-term statistics for the Energy dashboard. The first rate schedule is Cobb EMC's NiteFlex.
